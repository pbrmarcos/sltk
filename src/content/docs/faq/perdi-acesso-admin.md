---
question: Só tinha um admin e ele saiu — como recupero acesso?
category: admin
tags: [admin, recuperacao, emergencia, papel]
---

Não faça isso: **mantenha sempre pelo menos 2 usuários com papel `admin`** ativos. Se você chegou nessa situação, a UI não vai te ajudar — o papel `admin` só pode ser concedido por outro `admin`. Abra chamado urgente para o suporte da Solutek (ou para quem administra a infra Supabase) com prova de identidade corporativa; o vínculo será criado direto no banco via script auditado. Depois, imediatamente promova um segundo `admin` de contingência e documente em `/admin/usuarios`.
