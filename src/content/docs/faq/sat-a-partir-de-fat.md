---
question: Quando uma SAT é criada automaticamente pelo FAT?
category: pos-vendas
tags: [sat, fat, ressalvas]
---

Quando o FAT é homologado como **Aprovado com ressalvas**, o sistema cria uma SAT no Pós-vendas copiando as RNCs residuais. FAT **Aprovado limpo** não gera SAT; FAT **Reprovado** exige novo FAT (também não gera SAT).
