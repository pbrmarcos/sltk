---
question: Desativei um usuário — o histórico dele some?
category: admin
tags: [admin, usuarios, desativacao, historico]
---

Não. Desativar bloqueia login e encerra sessões ativas, mas **preserva todo o histórico**: apontamentos de H/H, cards executados, aprovações de OC, comentários, uploads. Os cards em aberto continuam atribuídos ao usuário desativado — reatribua-os antes de arquivar. Reativar devolve o acesso com os mesmos papéis anteriores. Exclusão permanente por LGPD só via chamado interno para o admin executar no banco.
