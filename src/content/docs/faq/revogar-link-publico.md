---
question: Como revogo um link público que já enviei ao cliente?
category: documentos
tags: [link, token, revogar, compartilhamento]
---

Abra o documento → aba **Compartilhamentos** → localize o link → **Revogar**. O link para de funcionar imediatamente e o cliente vê uma mensagem de acesso expirado. Você pode gerar outro com token novo depois, se necessário. Cada revogação fica registrada com autor e data.
